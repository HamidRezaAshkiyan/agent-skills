## Disambiguation Tips

- **✨ vs 💄**: Use `✨` for functional features (even if they include UI); use `💄` when the change is purely visual/CSS/styling.
- **♻️ vs 🎨**: Use `♻️` for structural/logic refactoring; use `🎨` for formatting, whitespace, lint-style cleanup, or file organization.
- **🐛 vs 🚑️**: Use `🐛` for normal bug fixes; reserve `🚑️` for urgent production hotfixes.
- **🔧 vs 🔨**: Use `🔧` for config files (`.json`, `.yaml`, `tsconfig`, `.csproj` settings); use `🔨` for build/dev scripts (`Makefile`, `install.sh`, npm scripts).
- **🔥 vs ⚰️**: Use `🔥` when deliberately deleting features/files; use `⚰️` when pruning unreachable dead code.
